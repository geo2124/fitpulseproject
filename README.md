# FitPass Access

Think as a premier web and mobile application developer, with very advanced graphic design skills

I want to build the front end of a project, looking very attractive and dynamic and advanced visually, looking like a real mobile app with sticky navigation on mobiles. 

The project is called fitpulse, create a generic logo based on the idea of this system is your key to open all the gym doors since it is an app where you can have a subscription that gives you access to multiple gyms. 

So build a front end, very visual and professional and dynamic UI/UX, make it very attractive and with features that shows high technology, the system offers multiple bundles of sponsorships that grants access to multiple gyms in multiple area, find the gyms around you and get instant access, this is also applicable to classes, pilates and any fitness activity center, all this is browsable and locatable by categories and distance and time availability. This option is for people who want to train and for private trainers who wants access to train their clients as well, they buy their package and can have multiple customers in different areas. Build features related to this idea as well. 

This system also has a portal for gym competitions, standings, head to heads, events done simultaneously, for example in calisthenics, most push ups, strongest deadlift... With contestants bringing points to the gyms. We see tables, standings, power rankings and all what can be elaborated. 

Build any more feature that you think is worth making it a very strong and top tier business. 

Build it with mock data, photos, locations, people, make it the realest fully testable prototype and demo possible. 

Colors you can use are black, gold, silver, red or light green or light blue
